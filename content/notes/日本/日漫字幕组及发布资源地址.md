# 日漫字幕组及发布资源地址

> 主要整理制作日漫中日双语字幕的字幕组，以及它们的官方频道、字幕存档和公开发布页。
>
> “简日”通常指简体中文 + 日文；“繁日”指繁体中文 + 日文；“简繁日”指简体中文 + 繁体中文 + 日文。不同字幕组并非每部作品都制作双语，查找时应以具体作品的发布标题为准。

## 最常用的公开索引

| 平台 | 地址 | 用途 |
| --- | --- | --- |
| AniBt | [anibt.net](https://anibt.net/) | 字幕组发布与订阅平台，绿茶字幕组明确以此为首发平台 |
| 蜜柑计划 Mikan | [mikanani.me](https://mikanani.me/) | 按字幕组或番剧订阅，查看作品年表 |
| ACG.RIP | [acg.rip](https://acg.rip/) | 按字幕组、番名查找发布记录 |
| 动漫花园 | [share.dmhy.org](https://share.dmhy.org/) | 传统动漫资源索引，部分字幕组会同步发布 |
| Anime Garden | [animes.garden](https://animes.garden/) | 动漫花园镜像及资源索引 |

## 其他项目型字幕组

以下字幕组可能只针对部分作品、OP/ED 或特定企划制作双语字幕，建议在 [AniBt](https://anibt.net/)、[Mikan](https://mikanani.me/) 或 [ACG.RIP](https://acg.rip/) 中按组名和番名检索：

- 今晚月色真美：可先查看 [AniBt 组页面](https://anibt.net/group/tsukigakirei)
- SFSub：主要通过各动漫索引站检索具体作品
- 三明治摆烂组：以部分 OP/ED、特效字幕或合作项目为主
- 漫猫字幕组、爱恋字幕社：仍有活跃发布，但并非每部作品都提供日文对照字幕

## 推荐检索格式

```text
番名 简日双语
番名 繁日内嵌
番名 简繁日内封
番名 字幕组名
```

优先查看字幕组自己的站点、Telegram、GitHub 或作品页，并遵守各组的转载说明和版权要求。
