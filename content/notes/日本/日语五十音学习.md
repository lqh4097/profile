# 日语五十音图与假名学习手册

> [!TIP] 学习提示
> - **平假名（ひらがな）**：用于日常本土词汇、语法假名、汉字注音（振仮名）。
> - **片假名（カタカナ）**：用于外来语、拟声拟态词、人名地名及强调。
> - 代码块中的字母（如 `a`）为对应假名的罗马字发音。

> [!NOTE] 易混淆发音说明
> - じ (ji) 与 ぢ (ji)：发音完全一致。现代日语日常书写 **99% 使用 じ / ジ**。
> - ず (zu) 与 づ (zu)：发音完全一致。现代日语日常书写 **99% 使用 ず / ズ**。

## 5. 促音与长音规则

### 5.1 促音（っ / ッ）
- **形式**：小写假名 `っ`（片假名 `ッ`）。
- **规则**：不发音，停顿一拍。键盘输入时**双写后方的辅音字母**。
  - 例：`かかった` (ka**k**atta) / `チケット` (chi**k**etto)

### 5.2 长音（長音）
- **规则**：音节延长一拍发音。
- **平假名长音规律**：
  - あ段 + **あ** （例：おかあさん）
  - い段 + **い** （例：おにいさん）
  - う段 + **う** （例：くうき）
  - え段 + **い** / え （例：せんせい / おねえさん）
  - お段 + **う** / お （例：ありがとう / とおる）
- **片假名长音**：统一使用长音符号 **ー**（例：コーヒー、ラーメン）。
