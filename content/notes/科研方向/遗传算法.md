# 算法概述
*遗传算法是一种模拟达尔文生物进化论的随机搜索启发式算法，是一种经典的进化计算算法*
核心思想：通过对种群进行选择、交叉和变异等遗传操作，使优良个体在进化过程中逐渐占据主导，从而在复杂的搜索空间中逼近或找到最优解（枚举法、启发式算法、搜索算法）
常用于：函数优化、组合优化、生产调度问题等


# 算法基本流程
算法主要包括：编码、产生初始种群、计算适应度、遗传操作（选择交叉变异）、模拟结果
初始化 -->评估-->选择-->重组-->变异-->新一代

# 遗传基因型表示
遗传基因型的选择：浮点编码、二进制编码等 
完全性、封闭性、紧致性、可扩展性、多重性、个体可塑性、模块性、冗余性、复杂性

# 适应度函数的选择
1.单值、连续、非负、最大化
2.合理、一致性
3.计算量小
4.通用性强

尺度变换：线性变换、指数变换、幂函数变换
控制个体差异，在收敛速度和多样性之间做平衡

# 遗传算子
选择算子：按比例的适应度分配、基于排序的适应度分配
常用方法：轮盘赌选择、随即遍历抽样法、局部选择法、锦标赛选择法
如何决定谁更容易留下来

交叉算子：实值重组、二进制交叉（单点/多点/均匀）
基因如何组合

变异算子：实值变异、二进制变异
常用于跳出局部最优解

# 遗传算法五个重要的函数模块
编码函数、适应度函数、选择函数、交叉函数、变异函数
算法设计的注意事项：
1.个体适应度的计算方法是由适应度函数决定的
2.交叉概率一般比较大；变异概率一般比较小
3.产生新一代群体时，必须采用最优个体保留机制，即将上一代最优个体直接复制到下一代新群体中，若不保留，算法不收敛
4.遗传算法的终止条件一般有两种：一是完成了预定的进化代数；二是种群中的最优个体在连续若干代中没有改进或平均适应度在连续若干代基本没有改进

# 5进化计算
进化计算的三大分支：遗传算法、进化规划、进化策略

进化计算=进化算子+进化操作+选择策略+进化计算理论

遗传算法GA：模拟生物交配；靠二进制，杂交
进化策略ES：模拟个体在环境中的适应性突变
（协方差矩阵自适应进化策略-CMA-ES）
进化规划EP：物种行为的演化；进化的动力来自于变异
遗传程序设计GP：实现自动编程，与llm生成代码不一样：llm是依据现有代码，而GP是自己演化

# NSGA-2
基于支配的多目标分解算法
「快速非支配排序」
「拥挤距离」
算法流程：
-->先生成初始种群，包含n个个体
-->将这n个个体进行非支配排序，重要的是rank 1
-->再进行拥挤距离的排序，在同一个rank里再继续排序
-->在这n个个体里，用锦标赛选择法选择子代，二进制交叉法交叉，多项式变异法进行变异，产生n个子代个体
-->将n个父代和n个子代合并成2n的种群
-->新的种群进行非支配排序，排序后进行拥挤距离计算，计算到n个个体后截断，保留前n个优秀个体，这n个就是下一个新生种群，一个循环结束
