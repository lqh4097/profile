
# 解决问题：边缘算力宽带受限
如何通过知识蒸馏在大幅压缩模型规模的同时最大限度保留云端教师模型的声学表征能 力，并在“点端-区域端-云端”异构硬件间实现分层协同与动态负载均衡，是支撑 PAM 规模化野外部署的关键技术挑战。




研究方向：
研究内容一：面向边缘轻量化的单目标进化NAS方法
研究内容二：面向边云协同的多目标进化NAS方法
问题：如何在 RK3566 这种低算力设备上，自动搜索出适合鸟鸣识别的轻量网络结构，使其在精度和推理延迟之间达到最优平衡
NAS+多目标优化 +RK3566部署

研究约束：RK3566硬件感知的多目标NAS
应用场景：鸟鸣声学场景适配
实验手段：Qwen2.5-Audio 蒸馏


研究方向的创新点
**A. 特定领域的稀缺性（被动声学 + 鸟鸣识别）**
大部分 NAS 研究都在跑 ImageNet（图像）或语言模型。在被动声学场景下做鸟鸣识别 ，处理的是时频稀疏的信号 。  
切入点：通用的 NAS 算子可能不适合音频。可以设计一套专门针对鸟鸣频谱特征的搜索空间（如专门捕获长距离频率关联的算子）。
**B. 针对特定硬件的深度优化（RK3566）**
很多论文只在模拟器上跑。本研究明确提出了针对 RK3566  等资源受限设备。  
切入点：RK3566 的 NPU 对不同算子的加速效果差异巨大。可以通过实验证明：通用轻量模型（如 MobileNet）在 RK3566 上并不是最优的，而搜出来的“不规则”架构反而跑得更快。 这就是强有力的实验数据。
**C. 边云协同与自监督的结合**
汇报材料中提到了自监督处理机制 和大模型（Qwen 2.5-Audio）演化溯源 。  
切入点：目前大部分 NAS 是监督学习。研究如何利用云端大模型的“知识”来指导边缘端小模型的“进化”（即蒸馏驱动的进化搜索 ），这个逻辑非常完整且符合前沿趋势

具体创新点：
改进 1:硬件约束引导的初始化
* 不随机初始化种群,而是先生成一批极轻量架构(低 channels、少 layers)和一批高精度架构
* 确保初始种群就覆盖 Pareto 前沿的两个极端
改进 2:代理模型辅助进化(Surrogate-assisted Evolution)
* 完整训练每个候选架构太慢(几十 epoch × 100个体 × 50代 = 灾难)
* 前 5-10 epoch 的 validation accuracy 与最终 accuracy 高度相关
* 使用 early-stop proxy:训练 5 epoch 即评估,大幅加速搜索
改进 3:MOEA/D + 权重向量引导
* MOEA/D 在 NAS 场景中通常比 NSGA-II 收敛更快(因为通过权重向量显式引导搜索方向)
* 同时实验 NSGA-II 和 MOEA/D,比较它们在 NAS 上的表现

# 实验设计：两个改进的消融实验

核心实验部分。需要跑以下四组实验：

| 实验组          | 初始化   | 评估方式          | 目的     |
| ------------ | ----- | ------------- | ------ |
| **Baseline** | 随机初始化 | 完整训练 50 epoch | 基准对照   |
| **+A only**  | 分层初始化 | 完整训练 50 epoch | 验证改进 A |
| **+B only**  | 随机初始化 | 代理评估 + 定期校准   | 验证改进 B |
| **+A+B**     | 分层初始化 | 代理评估 + 定期校准   | 验证组合效果 |

每组跑 50 代，种群大小 40，记录：
```
指标：
├── Hypervolume（每代记录）
├── IGD / GD（生成距离，衡量收敛性）
├── Pareto 前沿大小
├── 总 wall-clock 时间（最关键）
└── 最终前沿上最优个体的真实 accuracy + latency
```

**预期结果**：

- +A only：初始 HV 高，收敛快于 baseline，但总时间相近
- +B only：总时间约为 baseline 的 1/5，最终 HV 略低于 baseline（代理误差）
- +A+B：总时间最短，最终 HV 最接近 baseline（甚至因搜更多代而超过）

**算法改进：**
改进 A：硬件感知种群初始化 —— 具体实现
核心思路
随机初始化的种群在开始时大量浪费评估预算在"明显差"的架构上（比如 4 层 ×128 通道，延迟必然爆炸）。改进 A 在初始化阶段就保证种群覆盖 accuracy-latency 平面的两个极端和中间地带。


改进 B：代理模型辅助快速评估 —— 具体实现
核心思路
完整训练每个候选架构 50 epoch 太慢。改进 B 训练一个回归器，从"早期训练信号"预测"最终准确率"，让进化过程中只需训练 3-5 epoch。
