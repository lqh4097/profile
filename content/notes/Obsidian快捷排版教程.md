# Obsidian 快捷排版与常用操作教程

本教程为您汇总了在 Obsidian 中进行高效排版、文本格式化、表格制作以及常用快捷键的操作指南，帮助您快速掌握 Obsidian 的使用技巧。

---

## 一、 文本基础排版

在 Obsidian 中，你可以使用标准 **Markdown** 语法进行排版。

| 效果      | Markdown 语法   | Mac 快捷键             | 说明             |
| :------ | :------------ | :------------------ | :------------- |
| **加粗**  | `**需要加粗的文字**` | `Cmd + B`           | 强调重点内容         |
| *斜体*    | `*需要斜体的文字*`   | `Cmd + I`           | 次要强调           |
| ==高亮==  | `==需要高亮的文字==` | 无默认 (可设置)           | 突出显示，类似荧光笔     |
| ~~删除线~~ | `~~需要删除的文字~~` | 无默认                 | 用于标记已废弃或已完成内容  |
| `行内代码`  | `` `行内代码` ``  | `Cmd + Shift + `` ` | 用于标注公式、按键或代码词汇 |

> 💡 **小贴士**：选中一段文字后，直接按下快捷键（如 `Cmd + B`），可以直接在文字两端自动包裹对应的标记符号。

## 二、 标题与分割线

使用 `#` 加上空格来表示标题，`#` 的数量代表标题的级别（最多支持六级标题）。

```markdown
# 一级标题 (通常为文章大标题)
## 二级标题 (主要小结标题)
### 三级标题 (子小结标题)
#### 四级标题
```

*   **分割线**：在单独的一行输入三个或以上的减号 `---`、星号 `***` 或下划线 `___` 然后回车，即可生成一条横向分割线。

## 三、 列表与待办事项 (To-Do)

### 1. 无序列表
使用 `-`、`+` 或 `*` 加上 **空格**：
- 列表项 A
- 列表项 B
    - 使用 `Tab` 键可以缩进生成子列表。
    - 使用 `Shift + Tab` 可以取消缩进。

### 2. 有序列表
使用数字加上英文句号和 **空格**：
1. 第一步
2. 第二步

### 3. 待办事项 (Task List)
使用 `- [ ]` 加上 **空格**（注意方括号中间有一个空格）：
- [ ] 未完成的任务
- [x] 已完成的任务 (在中括号内写小写字母 `x`)
> 💡 **小贴士**：在列表中使用 `Cmd + Enter` 可以快速在“无序列表”、“代办事项（未完成）”、“代办事项（已完成）”以及“普通文本”之间进行切换。

## 四、 链接与引用

### 1. 内部链接 (双链 - Obsidian 的灵魂)
使用双路方括号 `[[ ]]` 链接到你笔记库中的其他文件。
*   输入 `[[` 会自动弹出文件联想列表。
*   链接到特定标题：`[[文件名#标题名]]`
*   别名链接（显示不同文字）：`[[文件名|显示的文本]]`

### 2. 外部链接
链接到网页地址：
`[显示文本](https://example.com)` (快捷键：`Cmd + K`)

### 3. 引用块
在行首使用右尖括号 `>` 加上空格：
> 这是一段引用文本。
> 换行也需要以 `>` 开头。

### 4. 炫酷的高亮呼叫块 (Callout)
Obsidian 支持非常好看的提示框，语法如下：
> [!NOTE]
> 这是一个蓝色背景的普通提示框。

> [!TIP]
> 这是一个绿色背景的技巧/建议提示框。

> [!WARNING]
> 这是一个黄色背景的警告提示框。

## 五、 表格制作

### 1. 基础语法
Markdown 表格使用竖线 `|` 分割列，减号 `-` 分割表头和内容。

```markdown
| 项目 | 快捷键 | 作用 |
| :--- | :---: | ---: |
| 快速切换 | Cmd + O | 查找并打开文件 |
| 命令面板 | Cmd + P | 调用所有功能 |
```

*   `:---` 表示左对齐（默认）
*   `:---:` 表示居中对齐
*   `---:` 表示右对齐

> 💡 **推荐**：您已经安装了但未启用的 **Advanced Tables** 插件，是制作表格的神器。去设置中开启它后，只需输入 `| 项目 |` 并按下 `Tab` 键，它就会自动帮您对齐和创建下一行。

## 六、 常用全局快捷键 (Mac)

掌握以下快捷键能让您的效率提升数倍：

*   🔍 **快速搜索并打开文件**：`Cmd + O`
*   ⚙️ **打开设置面板**：`Cmd + ,`
*   ⌨️ **打开命令面板**：`Cmd + P`（在这里可以输入并执行 Obsidian 的任何功能，如“切换双栏”、“导出 PDF”等）
*   🗂️ **显示/隐藏左侧边栏**：默认是 `Cmd + Alt + L`（可在设置中自定义）
*   📄 **在当前文件中查找**：`Cmd + F`
*   🌍 **在整个笔记库中搜索**：`Cmd + Shift + F`
*   🖥️ **关闭当前标签页**：`Cmd + W`
